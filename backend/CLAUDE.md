# Guia do Backend — Claude Code

Lê as instruções completas do projeto em [../CLAUDE.md](../CLAUDE.md).

Em resumo:
- Tu és o **Backend** (`backend/**`, `content/**`).
- O **Antigravity** é o **Frontend** (`frontend/**`).
- Não alteres ficheiros em `frontend/**`. Toda a integração é feita via `docs/api-contract.md` e `frontend.src.render.render_site(model)`.
- Comandos principais:
  - `npm test`
  - `npm run lint`
  - `npm run validate`
  - `npm run validate:production`
  - `npm run build:preview`
  - `npm run build:production`
