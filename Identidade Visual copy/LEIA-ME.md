# Cachupa Rst — identidade visual

Identidade construída a partir da logo fornecida. **Mesa Viva** é o nome da direção criativa, não uma alteração ao nome do restaurante.

## Abrir primeiro

- **Cachupa-Rst_Manual-de-Identidade.pdf:** manual de 12 páginas com marca, versões, proteção, tamanhos, cores, tipografia, grafismos, tom de voz, fotografia e aplicações.
- **Cachupa-Rst_Identidade-Visual.svg:** prancha vetorial com uma seleção visual do sistema.
- **SVG/01-manual.svg a SVG/12-manual.svg:** todas as páginas do manual em SVG separado.

## Elementos da marca

- **logo-original-recebida.svg:** cópia intacta do original.
- **logo-principal.svg:** versão a cores sobre branco.
- **logo-azul.svg:** versão numa cor sobre branco.
- **logo-negativa.svg:** versão branca sobre azul.
- **simbolo-rst.svg:** recorte vetorial do carimbo Rst existente, para uso secundário, como avatar. Mantém fundo branco. Preferir a logo completa sempre que houver espaço; o símbolo deve aparecer associado ao nome do restaurante no contexto.
- **grafismo-panela.svg, grafismo-vapor.svg e padrao-graos.svg:** elementos de apoio. Os desenhos de linha têm fundo transparente; não são padrões tradicionais.

## Modelos editáveis

- **social-feed-1080.svg:** 1080 × 1080 px.
- **social-story-1080x1920.svg:** 1080 × 1920 px; mensagem dentro de margens largas.
- **ementa-A4.svg:** proporção A4; definir tamanho final de 210 × 297 mm ao imprimir.
- **cartao-frente-90x50.svg / cartao-verso-90x50.svg:** proporção de 90 × 50 mm.
- **etiqueta-redonda.svg:** arte circular; dimensionar para o suporte real.
- **cinta-embalagem.svg:** proposta de composição; adaptar à caixa utilizada.

Os campos entre parênteses retos são para substituir. Contactos, pratos, preços e disponibilidade não foram inventados. As fotografias reais do restaurante continuam por inserir.

## Editar e exportar

1. Instalar os quatro ficheiros TTF da pasta Fontes. As três famílias incluem as suas licenças OFL.
2. Abrir o SVG num editor vetorial. As letras da logo são caminhos; os textos dos modelos continuam editáveis.
3. Os SVG incluem fontes incorporadas para visualização em navegadores compatíveis. Alguns editores ignoram fontes incorporadas, pelo que a instalação dos TTF é recomendada.
4. Manter as proporções e a margem de proteção da marca. Não esticar os ficheiros para mudar de formato.
5. Para redes sociais, exportar o SVG para PNG no tamanho indicado. SVG é o ficheiro de trabalho, não o formato de publicação habitual.
6. Os ficheiros estão em RGB. Antes de produção gráfica, adaptar sangria, corte, tamanho e perfil de cor às especificações do fornecedor. O manual é uma referência visual, não uma faca de embalagem ou arte-final com sangria.

## Cores digitais

- Azul: #006C9A — RGB 0, 108, 154
- Vermelho: #DD1A2A — RGB 221, 26, 42
- Amarelo: #FFED00 — RGB 255, 237, 0
- Branco: #FFFFFF
- Papel: #F5F1E8
- Tinta: #12323C

Os valores principais foram lidos do SVG fornecido. Não são apresentados como especificações oficiais da bandeira.

## Conteúdos

As frases são propostas de comunicação. A frase “Hoje há cachupa” deve ser usada quando o prato estiver disponível. A fotografia do site deve mostrar a receita e a porção efetivamente servidas.

A base de dados de produtos do Notion permanece separada e não foi alterada neste trabalho.
